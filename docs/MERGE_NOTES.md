# 两个 xiaofang 版本的合并取舍

## 从 cwm-peace/xiaofang 保留

- 小方的整体交互范式：倾斜选择、动作确认、摇动触发。
- 沙漏“粒子落下并堆积”的核心体验。
- 温度、声音开关、表情、睡眠/动作唤醒等产品级细节。
- “倒扣/长时间静止进入低功耗”的思路。

不再保留：
- ATmega328P 专用 LowPower；
- MAX7219/LedControl；
- AT24C16 地图存储；
- 大型 `.ino` + 多个阻塞 `while(flag)`。

## 从 LittleGuest/xiaofang 保留

- WS2812 RGB 表达；
- 模块化游戏设计；
- 随机迷宫与视野；
- 推箱子、下一百层、躲避方块；
- ESP-NOW 对打球；
- 最高分持久化思路。

不直接照搬 Rust/Embassy，而改为 ESP-IDF C + FreeRTOS/事件轮询。

## 已主动修复的问题

### 贪吃蛇自撞

Rust 版检查的是旧 `head` 是否和身体重叠，而不是 `next_head`。新版先计算下一头位置，并在非增长情况下排除本 tick 即将离开的尾格。

### 躲避方块方向

Rust 版 `pop_front + push_back` 配合 y 索引会让障碍向上移动，新障碍还可能直接出现在玩家行。新版 row0 明确为顶部，每 tick 向 row7 下移。

### 沙漏粒子丢失

Rust 版粒子从上半部移除后只做动画，没有进入下部长期状态。新版维护完整占用网格，粒子通过颈部并保留在下半腔体，完成后进入报警状态，检测到动作再重新开始。

### 迷宫终点

不使用随机近距离终点。新版 DFS 生成迷宫后，用 BFS 选距离起点最远的可达格。

### Pong 坐标系

网络统一使用 Host 世界坐标，Client 渲染时水平镜像球的位置，避免双方都把“自己”画在左侧却直接使用同一 x 坐标造成视觉语义冲突。

### 存储

不再使用固定 Flash 地址或 AT24C16 地址。统一使用 NVS key-value。

### 休眠

第二版只有 sleep/hibernation 音效，没有真正 Deep Sleep。新版关闭显示/ESP-NOW后配置 MPU6050 Motion Interrupt，通过 GPIO33 EXT0 唤醒。

## 暂缓功能

### 音乐频谱

第二版已有 FFT 思路，但当前硬件条件没有麦克风，因此不应把不存在的硬件当成完成品。GPIO35 已预留 ADC1。以后增加麦克风后，应使用固定采样率 ADC continuous/DMA，再做 FFT；不要使用无固定采样周期的 oneshot 循环。

### 电池/充电

未指定充电管理芯片、电池采样比例和充电状态 GPIO，因此只预留 GPIO34。确定硬件后再补充电量曲线与充电动画。

### 4G

当前只锁定 UART2 GPIO16/17 和辅助 GPIO，不假设 AT 指令。型号确定后再加具体驱动。
